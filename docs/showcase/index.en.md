# Showcase

Agentic development, using EDChar as the example.

EDChar was built by Thore Schuchardt working with several Claude Code instances. Each instance has its own repository, its own CLAUDE.md and its own permissions. They do not talk to each other directly. A shared ticket board is the only channel between them.

    Most pages are ready. "Lessons learned" and "Limits and transferability to teams" are still being written by Thore Schuchardt.
